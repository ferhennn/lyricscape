# Your tracks

Drop audio files here and they appear in LYRICSCAPE's Library.

## How to add a song

1. Copy an audio file into this folder.
   `mp3 · m4a · aac · ogg · opus · wav · flac`
   A name like `Artist - Title.mp3` is read as artist + title if the file has
   no tags.
2. Run `npm run tracks` (also runs automatically on `npm run dev` / `npm run build`).
   This reads the file's ID3 / Vorbis tags, pulls embedded cover art into
   `.covers/`, and rewrites `manifest.json`.
3. That's it. The song shows up under **Your tracks** in the Library, and
   time-synced lyrics are fetched from [LRCLIB](https://lrclib.net) by
   title + artist + duration.

## Lyrics

- **Automatic:** LRCLIB is queried at play time. No setup.
- **Override / correct:** drop a `.lrc` file with the **same base name** as the
  audio (`Artist - Title.lrc`) — it takes priority over LRCLIB.

## manifest.json

Regenerated by `npm run tracks`. Hand edits to `title`, `artist`, `album`,
`lrc`, `scene` are preserved on the next run (matched by `file`). Optional
per-track `"scene"`: `room · hallway · void · ocean · stars · smoke`.

```json
[
  {
    "id": "artist-title",
    "file": "Artist - Title.mp3",
    "title": "Title",
    "artist": "Artist",
    "album": "Album",
    "durationMs": 213000,
    "cover": ".covers/artist-title.jpg",
    "scene": "room"
  }
]
```

## Copyright

These files stay on your machine (and in your repo if you commit them). Only
you can add them. LYRICSCAPE never downloads or ships copyrighted audio.
`manifest.json` and `.covers/` are committed; the audio files are git-ignored
by default (see `.gitignore`).
